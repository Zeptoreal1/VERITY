# Alt Spam
Automatic alternating-input spam for practicing wave zigzags.

- Mode selector (5 clicks, 7 clicks, nonstop), continuous mode, CPS, intensity, speed, burst frequency
- Input delay, right-input offset, buffer, jitter, ramp-up, countdown, auto-stop
- 5 preset slots (Load / Save / Clear) from the HUD panel
- All other options live in this mod's settings

Clicks are scheduled in **game time** (physics steps), so timing is frame-accurate.
